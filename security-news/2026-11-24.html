10 vulnerabilities added to CISA's exploited-in-the-wild catalog this week, 1 tied to ransomware.

One week of Security Weekly Digest, 8 stories, as published.

Exploited CVEs

CVE-2024-10441: Synology DiskStation Manager (DSM)

Synology DSM contains an improper encoding or escaping of output vulnerability in the system plugin daemon in Synology BeeStation OS (BSM) that could allow a remote attacker to execute arbitrary code via unspecified vectors.

Why it matters — Confirmed exploited in the wild. CVSS 9.8 (CRITICAL). Linked to known ransomware campaigns. CISA remediation deadline 21 Nov 2026 — already passed.

CVE-2026-133968: Project MONAI MONAI Label

Project MONAI MONAI Label contains a path traversal vulnerability that allows an unauthenticated remote attacker to write arbitrary files outside the intended datastore directory, potentially resulting in remote code execution.

Why it matters — Confirmed exploited in the wild. CVSS 9.8 (CRITICAL). CISA remediation deadline 26 Nov 2026 — 2 days out.

Exploited CVEs

CVE-2026-134624: N-able MailAssure

N-able MailAssure (SpamExperts) contains a server-side request forgery vulnerability in the LDAP synchronization connection check that allows an authenticated API user to connect to arbitrary internal hosts and ports, determine which are reachable, and send crafted data to internal services.

Why it matters — Confirmed exploited in the wild. CVSS 9.3 (CRITICAL). CISA remediation deadline 26 Nov 2026 — 2 days out.

Exploited CVEs

CVE-2026-129448: Apache Roller

Apache Roller contains a deserialization of untrusted data vulnerability that allows an unauthenticated remote attacker to execute arbitrary code via the XML-RPC endpoint, which accepts and deserializes vendor extension types before authentication. This CVE covers the same underlying vulnerability as CVE-2026-82384 but applies to a broader range of affected versions.

Why it matters — Confirmed exploited in the wild. CVSS 9.8 (CRITICAL). CISA remediation deadline 23 Nov 2026 — already passed.

CVE-2026-76466: Cisco Expressway Series

Cisco Expressway Series contains a use of hard-coded credentials vulnerability that allows an unauthenticated, remote attacker with persistent cookies and network access to execute commands as root on a clustered device via the database service.

Why it matters — Confirmed exploited in the wild. CVSS 9.8 (CRITICAL). CISA remediation deadline 23 Nov 2026 — already passed.

CISA KEV · 24 November 2026 · Read the original →

Exploited CVEs

CVE-2026-90817: Vanderbilt University Research Electronic Data Capture (REDCap)

Vanderbilt University Research Electronic Data Capture (REDCap) contains a code injection vulnerability which could allow an unauthenticated attacker to execute arbitrary code on the server. An attacker could exploit this via crafted HTTP requests that access an unintended controller route from a public survey context and supply a crafted file-path or stream parameter during data import processing. Exploitation requires knowledge of a valid public survey hash.

Why it matters — Confirmed exploited in the wild. CVSS 9.8 (CRITICAL). CISA remediation deadline 21 Nov 2026 — already passed.

CISA KEV · 24 November 2026 · Read the original →

Exploited CVEs

CVE-2026-115731: Perforce Puppet Enterprise

Perforce Puppet Enterprise contains a deserialization of untrusted data vulnerability in Puppet’s report-processing code that allows a client with any CA-signed agent certificate to execute arbitrary code on the Puppet Server as the service user by submitting a report containing a crafted rich-data type through a PUT request. If the certificate authority automatically signs requests without strong verification, an unauthenticated network attacker can obtain a valid certificate and exploit the vulnerability.

Why it matters — Confirmed exploited in the wild. CVSS 9.4 (CRITICAL). CISA remediation deadline 01 Dec 2026 — 7 days out.

CISA KEV · 24 November 2026 · Read the original →

Supply Chain

Microsoft Agent Framework PyPI Package Hacked

Threat actors compromised Microsoft's `agent-framework` PyPI package (versions 1.26.1 and 1.26.2, published November 17, 2026) to deliver a credential stealer. The malicious versions were quarantined from the Python Package Index repository, but the method of obtaining publishing access remains unclear.

Why it matters — Developers using Microsoft's `agent-framework` PyPI package must verify their versions and rotate credentials if exposed, as supply chain attacks target trusted open-source components.
