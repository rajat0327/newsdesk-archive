China-Linked Storm-1175 Deploys StormEncryptor Ransomware

Microsoft disclosed that China-linked threat actor Storm-1175 is deploying a new ransomware strain, StormEncryptor, marking a shift from their previous use of Medusa ransomware. Initial access likely involves exploiting CVE-2026-18577 in N-able N-central, with rapid progression from access to encryption.

Why it matters — Organizations using N-able N-central must immediately patch CVE-2026-18577 and implement robust monitoring for rapid post-compromise activity to defend against Storm-1175.
