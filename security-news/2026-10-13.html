5 vulnerabilities added to CISA's exploited-in-the-wild catalog this week.

One week of Security Weekly Digest, 6 stories, as published.

Exploited CVEs

CVE-2021-3199: ONLYOFFICE Docs

ONLYOFFICE Docs contains a path traversal vulnerability that can occur when JWT is used, via a /.. sequence in an image upload parameter and could allow for remote code execution.

Why it matters — Confirmed exploited in the wild. CVSS 9.8 (CRITICAL). CISA remediation deadline 11 Oct 2026 — already passed.

Exploited CVEs

CVE-2015-3306: ProFTPD

ProFTPD contains an improper access control vulnerability that could allow remote attackers to read and write to arbitrary files via the site cpfr and site cpto commands.

Why it matters — Confirmed exploited in the wild. CVSS 10.0 (CRITICAL). CISA remediation deadline 11 Oct 2026 — already passed.

Exploited CVEs

CVE-2015-5477: ISC BIND

ISC BIND contains a data processing errors vulnerability that could allow remote attackers to cause a denial of service via TKEY queries.

Why it matters — Confirmed exploited in the wild. CVSS 7.5 (HIGH). CISA remediation deadline 11 Oct 2026 — already passed.

Exploited CVEs

CVE-2016-3081: Apache Struts

Apache Struts contains a command injection vulnerability that could allow remote attackers to execute arbitrary code via method:prefix when Dynamic Method Invocation is enabled.

Why it matters — Confirmed exploited in the wild. CVSS 8.1 (HIGH). CISA remediation deadline 11 Oct 2026 — already passed.

CISA KEV · 13 October 2026 · Read the original →

Exploited CVEs

CVE-2023-22894: Strapi

Strapi contains a cleartext storage of sensitive information vulnerability that could allow attackers with access to the admin panel to discover sensitive user details via the query filter. The impacted product(s) could be end-of-life (EoL) and/or end-of-service (EoS). Users are advised to discontinue use and/or transition to a supported version. This vulnerability can be chained with CVE-2023-22621 to achieve remote code execution.

Why it matters — Confirmed exploited in the wild. CVSS 4.9 (MEDIUM). CISA remediation deadline 11 Oct 2026 — already passed.

CISA KEV · 13 October 2026 · Read the original →

Exploited CVEs

SonicWall SMA1000 Vulnerability Exploited

Threat actors began actively exploiting CVE-2026-102255, a critical pre-authenticated server-side request forgery (SSRF) vulnerability in SonicWall Secure Mobile Access (SMA) 1000 appliances, within days of its public disclosure on October 6, 2026. SonicWall released patches for versions 12.4.3-03670 and 12.5.0-03082, urging customers to update their 6210, 7210, and 8200v models.

Why it matters — Organizations using affected SonicWall SMA1000 appliances must immediately apply patches and verify system integrity, as attackers are rapidly exploiting this critical vulnerability to gain unauthorized access.
