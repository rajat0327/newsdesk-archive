Shifting HBM4 Controller Functions Closer To Memory (UC Riverside)

Research from UC Riverside explores controller partitioning strategies for HBM4 memory stacks. Because HBM4 transitions the stack's base die to an advanced logic process node, memory control functions can be split between the host SoC and the base die itself.

Why it matters — Using logic nodes for memory base dies allows migrating timing-critical memory control logic directly into the stack, freeing host SoC die area and simplifying routing.

Reducing High-Bandwidth Flash Latency In GPU Systems (Georgia Tech, Nvidia, Stanford)

Researchers from Georgia Tech, Nvidia, and Stanford introduce SlipStream, an architecture replacing DRAM dies in HBM stacks with High-Bandwidth Flash (NAND) to expand GPU memory capacity up to 16x for LLM inference. The design uses architectural techniques to mitigate NAND's higher access latency and SRAM buffer overheads.

Why it matters — Replacing DRAM with NAND flash inside high-bandwidth memory stacks enables 16x capacity scaling for inference if host SRAM management masks flash read latency.

Silicon Motherboard Enables Double-Sided Integration of ICs and Passive Components

Nisshinbo Micro Devices introduced Silicon Motherboard (Si-MB), a 3D packaging technique that integrates ICs and passive components on both sides of a silicon substrate. The complete assembly is enclosed in a single molded package to minimize board space.

Why it matters — Double-sided component mounting on silicon substrates reduces interconnect lengths and parasitic inductance while shrinking overall package footprint.

AMD Ships 2nm EPYC Embedded Processors

AMD began shipping its 6th-gen EPYC "Venice" embedded processors, the first data center CPUs built on TSMC's 2nm process with CoWoS-L advanced packaging. These CPUs feature up to 256 Zen 6 cores and offer up to 2.7x peak memory bandwidth.

Why it matters — This marks the formal extension of 2nm process technology into server CPUs, enabling higher performance and memory bandwidth for embedded AI and test systems.

Model Tracks Bond Front Velocity in Lubrication-Mediated Bonding of Flexible Substrates (imec)

An imec researcher has modeled the bond front velocity in lubrication-mediated bonding of flexible substrates. This process is critical for 3D stacking and heterogeneous integration, enabling novel interconnect architectures for integrated circuits.

Why it matters — Quantifying bond front velocity provides a mathematical basis to optimize throughput and yield in lubrication-mediated 3D stacking.
