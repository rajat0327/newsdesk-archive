Shipping JPEG XL in Chrome

Chrome is shipping support for JPEG XL, a modern image format that provides superior compression compared to standard JPEG. It features native HDR support and the ability to perform lossless transcoding from existing JPEG files.

Why it matters — Lossless transcoding allows for modernizing image delivery without losing original data or quality.

What's New in WebGPU (Chrome 155-156)

Chrome 155-156 updates for WebGPU include the WGSL fragment_depth extension and support for unaligned texture compression. It also introduces srgb-linear and display-p3-linear color spaces alongside the snorm10-10-10-2 vertex format.

Why it matters — Support for display-p3-linear color spaces enables more accurate color rendering in high-performance graphics applications.

Bun v1.4.3

Bun v1.4.3 introduces 'bun check', a built-in TypeScript type checker that performs 3x to 6.4x faster than tsc. The release also significantly reduces idle CPU usage by up to 89% and improves JSON.parse performance via a JavaScriptCore upgrade.

Why it matters — Replacing tsc with an integrated type checker can reduce build times by up to 6.4x.
