SvelteKit 3 Ships with Configuration and Import Changes

SvelteKit 3 and Svelte CLI 1.0 were released on October 1, 2026, bringing significant changes including moving configuration to `vite.config.ts` and standardizing the `$lib` alias to `#lib` using subpath imports. The release also formalizes the community add-on API.

Why it matters — Existing SvelteKit projects must update their build configuration to `vite.config.ts` and migrate internal module imports from `$lib` to `#lib`, requiring code changes across affected projects.
