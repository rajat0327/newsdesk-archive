Multimodal

SANA-Video 2.0: Hybrid Linear Attention with Attention Residuals for Efficient Video Generation

SANA-Video 2.0 is introduced as a hybrid video diffusion transformer, scaled to 5B and 14B parameters, designed for high-quality 720p video generation on a single GPU. It achieves quality comparable to full-softmax video DiTs while maintaining the favorable long-sequence scaling of linear attention by employing Hybrid Linear-Softmax Attention and Attention Residuals.

Why it matters — This paper details architectural innovations, specifically hybrid attention and attention residuals, that enable efficient and high-quality video generation, addressing a key scaling challenge in multimodal models.

AgentSWE: Can Coding Agents Build the Agent You Actually Want?

This paper introduces AgentSWE, a new benchmark designed to test whether coding agents faithfully serve user requirements, rather than merely appearing to. It addresses a critical assumption in the deployment of software-producing agents, which is currently untested by existing benchmarks.

Why it matters — A new benchmark for evaluating the faithfulness of coding agents, addressing the critical assumption that they will genuinely serve user requirements rather than just appearing to.

Agent-Reflex: Teaching Language Agents to Act Reflectively

This work proposes Agent-Reflex, a general training framework for language agents to learn reflection and failure recovery. It addresses the limitations of existing methods in providing supervision for agents operating in real deployments with noisy feedback and user interventions.

Why it matters — A general training framework for reflection learning and failure recovery can significantly improve the robustness and adaptability of language agents in real-world deployments with noisy feedback and user interventions.

LLMs & Reasoning

TPPO: Tracking-Value PPO For Language Model Reasoning

This paper addresses the challenge of standard PPO critics failing to track value evolution under sparse terminal rewards in language model reasoning. It analyzes the relationship between successive prefix values, showing they admit a Bayesian formulation to model this evolution.

Why it matters — Analyzing the relationship between successive prefix values can lead to improved PPO critics for language model reasoning, especially when dealing with sparse terminal rewards.

LLMs & Reasoning

Vela: User Behavior as Supervision Sparks LLM Intelligence

This work highlights that current LLMs, trained on static text, lack the "user dimension" intelligence needed for applications acting on long-term user behavior histories. It proposes using user behavior as supervision to infer preferences, intent, and future actions from weeks to years of data.

Why it matters — Training LLMs with long-term user behavior data can enhance their ability to infer user preferences and intent, crucial for personalized applications like assistants and recommendation systems.
