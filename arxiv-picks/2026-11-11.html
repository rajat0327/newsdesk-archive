Systems & Inference

LowRAM: Low-Rank Keys and Amortised Values for Composable KV Cache Compression at Test-Time

Identifies that within individual attention heads, value vectors are largely predictable from their corresponding key vectors during autoregressive decoding. Introduces LowRAM to exploit key-value correlation alongside low-rank keys for test-time KV cache compression.

Why it matters — Attention values can be predicted directly from key vectors within each head, providing a distinct axis for compressing KV cache memory footprint at test-time.

Agents & Tools

Don't Just Trust Your Memory: Evidence-Linked Memory Reduces Memory-Induced Degradation in LLM Agents

Examines memory-induced degradation in LLM agents, where adding external experience memory causes an agent to fail on tasks it would otherwise solve without memory. Finds that degradation occurs when agents derive incorrect lessons from past trajectories or misread and misapply valid ones.

Why it matters — Naive trajectory-based memory distillation can cause net performance loss by inserting incorrect or misapplied lessons into agent contexts.

Evaluation & Benchmarks

Beneath the Surface: What We Overlook When We Talk About Agent Evolution

Evaluates four weight-free agent harness evolution methods across general and coding tasks in 16 experimental settings. Uses controlled expansion, component interventions, and admission replays to investigate whether benchmark score gains translate to reliable, efficient, and transferable improvements.

Why it matters — Benchmark score increases gained via weight-free agent harness modifications do not reliably reflect efficient or transferable system improvements across tasks.

Systems & Inference

InfraRSI: Harnessing Recursive Self-Improvement for Training Infrastructure

Focuses on automated optimization of distributed LLM training setups, where launch configurations, operator kernels, and communication schedules are tightly coupled. Introduces InfraRSI, an agentic harness built to navigate failure modes like OOM boundaries, compiler conflicts, measurement jitter, and silent numerical drift.

Why it matters — Automating distributed training optimization requires navigating interdependent execution errors like OOMs and measurement jitter rather than optimizing isolated operators.

Multimodal

SplatAnything: Gaussian Spacing Normalization for Feed-forward 3DGS across Arbitrary Scenes

Identifies a failure mode in feed-forward 3D Gaussian Splatting where predicting attributes in a radial-distance-normalized space leaves spacing between neighboring Gaussian centers variable across scene scales and camera configurations. Proposes Gaussian Spacing Normalization to eliminate these systematic geometry shifts.

Why it matters — Canonicalizing global radial distance in feed-forward 3DGS is insufficient; normalizing local spacing between neighboring Gaussian centers prevents scale-induced visual shifts.

arXiv · 11 November 2026 · Read the original →

Agents & Tools

The Last Mile to the Real World: Agent-Native Primitives as Reusable Building Blocks for Solving Real-World Tasks

Evaluates frontier LLM agents on Terminal-Bench 4.0, showing that models like GPT-5.6 Sol with Codex (37.3%) and Claude Opus 5 with Claude Code (51.8%) fall short on real-world tasks. Identifies that task execution typically breaks at the specific transition step between reaching a needed resource and applying it.

Why it matters — LLM agent failures on command-line benchmarks stem primarily from the execution bridge between accessing a resource and correctly applying it.

arXiv · 11 November 2026 · Read the original →
