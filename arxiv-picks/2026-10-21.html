Training & Efficiency

VLA-Rolling: Fewer Denoising Steps, Better Control via Adaptive Action Reuse

This paper addresses the inefficiency of flow-matching vision-language-action (VLA) models that discard the 'action tail' during receding-horizon replanning. It introduces VLA-Rolling, which adaptively reuses the unexecuted portion of previous action chunks to reduce the number of denoising steps needed for the next update.

Why it matters — Reusing the unexecuted action tail in receding-horizon control reduces the computational cost of frequent replanning without losing the temporal coherence of the generated trajectory.

PAR: Progress-Aligned Recurrence for Length Generalization in State Tracking

Progress-Aligned Recurrence (PAR) addresses the failure of looped language models to generalize to longer problems despite increased test-time iterations. It trains the model so that each iteration k corresponds to a specific progress point, preventing the recurrent state scale from drifting during extended execution.

Why it matters — Aligning specific iterations to progress steps prevents recurrent state drift and enables looped models to generalize to longer sequences than seen during training.

Kronecker Delta Rule for Long Context Linear Attention

KronLSTM introduces a linear attention architecture based on the Kronecker Delta Rule for associative matrix memories. This mechanism allows for targeted memory revision by modifying the memory matrix along only a single direction, which minimizes interference with previously stored information.

Why it matters — Updating associative memory along a single matrix direction allows for targeted error correction with minimal interference to existing stored information.

OpenVLHarness: Real World Visual Agentic Tool-Use with Multimodal Memory

A controlled study of 22 benchmarks reveals that increasing the inference budget of Multimodal LLMs provides only marginal gains for tasks requiring grounded perception or numerical measurements. The authors introduce OpenVLHarness to facilitate agentic tool-use and multimodal memory as a more effective alternative to raw scaling.

Why it matters — Scaling inference-time compute is insufficient for tasks requiring grounded perception, proving that external tool-use is a necessary architectural component for visual agents.

Agents & Tools

Focused Omni-Modal GUI Agents

This research identifies that uniform exposure to streaming omni-modal data in GUI agents leads to context clutter, as relevance is often transient. The proposed approach focuses on filtering the observation stream to prevent executed actions and historical states from overwhelming the model's current decision-making.

Why it matters — Treating streaming omni-modal context as transient rather than persistent prevents feedback loops where previous actions clutter the model's current decision-making space.

SpecMRL: Redesign Matryoshka Representation Learning within Parametric Spectrum

SpecMRL improves upon Matryoshka Representation Learning (MRL) by adding an explicit constraint to the feature space reorganization. This ensures that the leading portion of a nested representation provides a genuinely compact and effective encoding rather than just a truncated version of the full vector.

Why it matters — Adding explicit constraints to the feature space reorganization ensures that the most compact prefixes in Matryoshka models maintain high representational quality.
