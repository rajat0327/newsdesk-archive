Regulation

RBI Tightens Non-Bank Cyber Rules

The Reserve Bank of India (RBI) issued consolidated Master Directions on Cyber Resilience and Digital Payment Security Controls for non-bank Payment System Operators (PSOs) on November 5, 2026. These rules mandate stronger board-level oversight, annual system audits, source code protection for critical applications, and stricter third-party security controls. Large and medium PSOs must comply immediately, while smaller operators have until April 1, 2028.

Why it matters — Non-bank PSOs must immediately implement new cybersecurity controls, including source code escrow for critical third-party software and 24/7 manned security operations centers, increasing compliance costs.
