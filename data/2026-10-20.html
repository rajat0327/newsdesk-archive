Álvaro Hernández: Open-source Citus matches PlanetScale's Neki at 10M QPS on half the data nodes

This post benchmarks open-source Citus against PlanetScale's published Neki benchmarks on distributed PostgreSQL workloads. It analyzes query throughput and node efficiency, demonstrating Citus achieving 10 million QPS on half the data nodes required by Neki.

Practice

Hubert 'depesz' Lubaczewski: Old tech is sometimes better – a case study based on blogpost from Now-Next…

The post tests the operational tradeoffs of audit logging using PostgreSQL triggers by comparing full-row snapshot logs against diff-only column updates. Through practical experiments, it measures how storing only changed columns yields a 5x reduction in log table storage size at the cost of higher trigger CPU execution time.

Why it matters — Diff-based trigger logging reduces audit table storage by 5x but introduces query execution overhead that can degrade transaction throughput.

Postgres

Chris van Eijk: CREATE POLICY IF NOT EXISTS in PostgreSQL: what works

This piece explores how to execute idempotent Row Level Security (RLS) policy changes in PostgreSQL despite the lack of native CREATE POLICY IF NOT EXISTS syntax. It evaluates three migration patterns across PostgreSQL 17 and 18, analyzing lock acquisition, execution gaps, and race conditions.

Why it matters — Idempotent policy deployment requires explicit lock management or defensive block execution to prevent race conditions during schema migrations.

Ridgeline details its production architecture overhaul, pairing ClickHouse Cloud with historical data stored in Apache Iceberg tables. Why it matters — Coupling object-storage Iceberg tables for cold historical data with ClickHouse for active analytical state allows querying multi-decade datasets without duplicating data.
