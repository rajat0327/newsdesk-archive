DoorDash Uses Multi Agent LLMs to Clean up 60,000 Feature Flags

DoorDash designed a multi-agent LLM system using Model Context Protocol (MCP), parallel agents, and isolated Git worktrees to automate the removal of stale feature flags. The system successfully resolved 45 out of 50 evaluated flags, generating usable pull requests in under 14 minutes at an average cost of $4.79 per cleanup.

Why it matters — Automating tedious codebase maintenance with LLMs can be highly cost-effective ($4.79 per cleanup) when combined with automated validation and isolated worktrees to ensure safety.
