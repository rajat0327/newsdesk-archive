CVE-2026-46300: Linux Kernel

Linux Kernel contains a missing initialization of a variable vulnerability that could allow for unintended modification of page-cache-backed data via failure to preserve the shared-fragment marker during socket buffer coalescing, causing ESP input processing to decrypt shared fragments in place. This vulnerability can be chained with CVE-2026-109618 and CVE-2026-109619 to implant PHP webshells and run commands as root.

Why it matters — Confirmed exploited in the wild. CVSS 7.8 (HIGH). CISA remediation deadline 31 Oct 2026 — already passed.

RBI Expands UPI Transaction Limits

The Reserve Bank of India (RBI) announced several UPI limit enhancements on November 7. These include increasing the UPI transaction limit for tax payments from ₹1 lakh to ₹5 lakh, raising the UPI 123Pay limit to ₹10,000, and increasing the UPI Lite wallet limit to ₹5,000 with a ₹1,000 per-transaction limit.

Why it matters — These changes directly expand the utility of UPI for higher-value transactions in specific categories and for feature phone users, making digital payments more versatile for a broader user base.
