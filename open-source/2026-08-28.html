Eight stable kernels with fix for a single vulnerability

The Linux kernel maintainers released eight stable kernel versions simultaneously to address a single vulnerability (CVE-2026-80590) that can cause a kernel panic. The vulnerability has been present in the codebase since Linux 2.6.27, affecting long-term stable releases spanning many years.

Why it matters — A single legacy vulnerability can require coordinated emergency releases across nearly a decade of stable branches, illustrating the massive maintenance tail of core open-source infrastructure.
