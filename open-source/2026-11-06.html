WordPress Core Critical Vulnerability Exploited

The U.S. Cybersecurity and Infrastructure Security Agency (CISA) has confirmed active exploitation of CVE-2026-119977, a critical Time-of-check Time-of-use (TOCTOU) race condition vulnerability in WordPress Core versions 4.7 through 7.1.3. This flaw allows unauthenticated remote code execution during software upgrades, with federal agencies facing a remediation deadline of November 6, 2026.

Why it matters — Organizations using affected WordPress versions must immediately patch or face unauthenticated remote code execution during routine upgrades, with federal agencies facing a strict deadline.
