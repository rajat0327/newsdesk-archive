Forks & Splits

Redict deprecated in favor of Valkey

Drew DeVault has announced the deprecation of Redict, the Redis fork created after Redis changed its license in 2024. Users are advised to migrate to Valkey, a permissively licensed Redis fork hosted by the Linux Foundation. Migration requires changing installed packages and configuration file names due to mutual compatibility between the projects.

Why it matters — Open source license-change forks often consolidate into foundation-backed alternatives, making API compatibility the key to low-friction migrations.

Governance

Manjaro Project e.V. non-profit organization created

Contributors to the Manjaro Linux project created Manjaro Project e.V., an independent non-profit organization based in Germany. The entity was established following a governance dispute between project contributors and Philip Müller, the project lead and CEO of the corporate entity Manjaro GmbH.

Why it matters — Creating an independent non-profit entity allows open source communities to decouple project governance from corporate leadership during corporate disputes.

Maintainers

Maintainers don’t need more AI bug reports. They need fixes.

Maintainers of open source projects are being overwhelmed by AI-generated security vulnerability reports, many of which contain duplicates or false positives. The cheap cost of generating automated scans places an unpaid triage burden on maintainers without offering actual code fixes.

Why it matters — Automated vulnerability scanning without human verification offloads triage costs onto open source maintainers, accelerating maintainer burnout.

Supply Chain

Inside Secretless Analysis: from CI identity to project-scoped access

Attackers force-pushed malicious commits onto release tags of popular GitHub Actions, including aquasecurity/trivy-action and tj-actions. CI pipelines referencing those version tags ran compromised code that extracted secrets from runner memory before proceeding with normal execution.

Why it matters — Pinning CI dependencies to mutable release tags rather than immutable commit hashes leaves build runner memory vulnerable to secret exfiltration.
