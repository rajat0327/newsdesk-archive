Android & Kotlin

Play Games Services v1 Deprecated

Google has deprecated the Play Games Services v1 SDK and APIs, following the deprecation of the Google Sign-in API. Developers must migrate to Play Games Services v2, as deprecated APIs were removed from the SDK in June 2026, Google Sign-In for Android API is no longer supported since September 2026, and the v1 SDK will be removed in June 2027, causing API calls to fail.

Why it matters — Games using Play Games Services v1 must migrate to v2 by June 2027 to avoid compilation errors and API call failures.
