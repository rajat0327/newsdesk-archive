Observability

Grafana UI Refresh, Managed Grafana 13.2

Grafana announced a significant visual UI refresh, introducing a new color system, typography, and theme, marking the biggest visual modernization since Grafana v7. Concurrently, Amazon Managed Grafana now supports in-place upgrades from version 12.4 to 13.2, bringing features like Git Sync for dashboards and dynamic dashboards.

Why it matters — Users will experience a modernized interface, and those on Amazon Managed Grafana can now leverage new features like Git-versioned dashboards and responsive layouts without manual migration.

Cloud Providers

AWS Service Deprecations, Sunsets

AWS announced several service lifecycle changes. Amazon Chime SDK SIP Media Application and Amazon WorkSpaces Secure Browser are moving to maintenance, becoming inaccessible to new customers from October 29, 2026. Amazon Managed Blockchain, Amazon DevOps Guru, AWS Backint Agent for SAP ASE, and AWS Infrastructure Composer are entering sunset, with end of support dates in late 2026 and 2027. Amazon Mechanical Turk reached end of support on September 29, 2026.

Why it matters — Customers using these services must plan migrations to alternative solutions or be aware of reduced support, as new customers cannot adopt services in maintenance, and sunset services will eventually cease operations.

Databases & Data Infra

Google Cloud AlloyDB Omni Web UI

Google Cloud released the AlloyDB Omni Web UI, a centralized graphical dashboard for managing self-managed PostgreSQL workloads across hybrid, multi-cloud, and air-gapped environments. This UI provides real-time insights into cluster health, hardware utilization, and query diagnostics.

Why it matters — Database administrators can now troubleshoot performance bottlenecks and monitor PostgreSQL deployments with a visual interface, reducing reliance on manual terminal commands and simplifying hybrid cloud management.
