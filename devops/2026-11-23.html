23 November 2026

AWS enhances multicloud connectivity, serverless compute, and observability with key infrastructure and developer tooling updates.

One week of DevOps Weekly Digest, 5 stories, as published.

Cloud Providers

AWS Interconnect Now Links to Azure

AWS Interconnect is now generally available for multicloud connectivity with Microsoft Azure, allowing customers to provision resilient, scalable private connections between the two cloud providers. This service is available in the us-east-1 (N. Virginia), ap-southeast-2 (Sydney), and eu-central-1 (Frankfurt) AWS Regions.

Why it matters — Teams can now establish direct, private network connections between AWS and Azure without building complex global multi-layered networks themselves, simplifying multicloud deployments.

Cloud Providers

Lambda MicroVMs Support x86 Architecture

AWS Lambda MicroVMs now support the x86 CPU architecture, providing developers the flexibility to run existing x86 applications without recompiling. This update expands on the existing Arm (AWS Graviton) support for MicroVM images.

Why it matters — Developers can now migrate existing x86-based serverless functions to Lambda MicroVMs without code changes, reducing migration effort and expanding deployment options.

aws.amazon.com · 23 November 2026 · Read the original →

Cloud Providers

Cognito User Pool Session Management

Amazon Cognito now offers user pool session management capabilities, giving developers better visibility and control over user sessions. This is a crucial update for securing applications and managing user access effectively.

Why it matters — Developers gain finer-grained control over user authentication sessions, enabling more robust security policies and improved user experience for applications using Cognito.

aws.amazon.com · 23 November 2026 · Read the original →

Kubernetes & Orchestration

EKS Auto Mode Gets Dynamic Resource Allocation

Amazon EKS Auto Mode now supports Dynamic Resource Allocation (DRA), allowing Kubernetes to dynamically assign hardware resources like GPUs based on workload requirements. This feature integrates with Karpenter for provisioning.

Why it matters — EKS users can now optimize resource utilization and cost for AI/HPC workloads by allowing Kubernetes to automatically provision and allocate specialized hardware as needed.

aws.amazon.com · 23 November 2026 · Read the original →

Observability

Athena System Tables for Observability

Amazon Athena now provides system tables for observability and auditing, offering insights into query execution, resource utilization, and user activity directly within Athena.

Why it matters — Data engineers and administrators can now monitor and audit Athena usage and performance using standard SQL queries, simplifying cost analysis and compliance reporting.

aws.amazon.com · 23 November 2026 · Read the original →
