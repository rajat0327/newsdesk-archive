Azure DevOps unveiled new features for GitOps integration, allowing teams to manage infrastructure and application deployments entirely through Git repositories. This includes enhanced pull request automation and drift detection capabilities.

OpenTofu, the open-source alternative to Terraform, released version 1.13.0 with significant improvements to multi-cloud state management and provider extensibility. New features include native support for cross-cloud resource tagging and enhanced module versioning.
