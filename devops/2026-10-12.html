GitHub overhauls Git infrastructure to handle 5x surge in AI agent-driven commits.

One week of DevOps Weekly Digest, 3 stories, as published.

CI/CD

GitHub Rebuilds Git for AI Agents

GitHub is redesigning its core Git infrastructure, shifting to Azure Blob Storage and independent compute workers. This change is in response to a five-fold increase in commits, reaching 7.38 billion in September 2026, primarily driven by AI coding agents.

Why it matters — Teams will see Git operations scale to agent-driven workloads, but must manage increased CI costs and review bottlenecks from higher commit volumes.

CI/CD

GitLab 19.4 Adds AI Agents, Cost Controls

GitLab 19.4 has been released, introducing new features such as goal-driven agents and enhanced cost controls. This update aims to provide more granular management over CI/CD pipelines and the integration of AI-powered workflows.

Why it matters — Teams can now define and manage AI agents with specific objectives within GitLab CI/CD, and gain more granular control over CI/CD pipeline costs.

InfoQ · 12 October 2026 · Read the original →

Cloud Providers

Google Cloud Introduces Gemini Agent

Google Cloud has introduced the Gemini agent, a new offering that enables developers to build agents capable of interacting with software to complete tasks. It incorporates computer use capabilities and integrates multi-agent features, tool search, tool calling, and context compaction from Codex.

Why it matters — Developers can now leverage Google Cloud's AI agent capabilities to automate complex workflows and integrate AI directly into their applications, reducing manual intervention.
