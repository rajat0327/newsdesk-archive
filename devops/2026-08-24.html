GitHub Suffers Major 8-Hour Outage

GitHub experienced a widespread outage on August 17, 2026, lasting 7 hours and 47 minutes, impacting core services like web interface, authentication, APIs, pull requests, issues, Actions, and Copilot. The incident was attributed to a capacity failure, specifically network saturation on Central US load balancers, exacerbated by a misfiring autoscaling policy and a 10x traffic spike from a latent VS Code retry bug affecting Copilot.
