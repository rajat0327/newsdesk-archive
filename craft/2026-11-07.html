Uber Builds MCP Gateway to Govern Access to 800+ Servers and 5,000+ AI Agent Tools

Uber built an MCP Gateway to standardize how AI agents discover and invoke services across 800+ MCP servers and 5,000+ tools. The system separates tool registration from runtime execution and includes automated API discovery, fine-grained access controls, sensitive data redaction, and response filtering.

Why it matters — Decouple agent tool registration from execution to centralize access control, payload redaction, and runtime discovery across large tool ecosystems.

Article: Systemic Approach to Memory, Knowledge, and Context in Agentic AI Architectures

This article outlines a systemic context engine architecture designed to select, inject, compress, and expire data before passing it to LLMs. It defines an operational framework separating context, memory, and knowledge using tiered storage, curated data, and token budgeting to prevent anti-patterns like context stuffing.

Why it matters — Manage LLM context lifecycle via tiered memory and token budgeting rather than raw prompt context stuffing.

Test and verification technique effectiveness with GPT-6 Astra

Dan Luu analyzes empirical testing performance when LLM agents are directed to use specific software verification techniques versus open-ended defaults. The evaluation notes that unguided agents frequently generate low-value unit tests compared to structured verification methods.

Why it matters — Explicitly constraining LLM verification methods prevents agents from defaulting to superficial unit tests.
