JioHotstar Benchmarks Knowledge Bases for AI Coding Agents

JioHotstar benchmarked six knowledge base retrieval techniques for AI coding agents across public benchmarks and an internal QA harness. The evaluation revealed that structural search excels at precise code tasks, while semantic retrieval is necessary for ambiguous requirements, highlighting key token cost and accuracy trade-offs.

Why it matters — Structural code search minimizes token usage for deterministic tasks, while semantic retrieval should be reserved for ambiguous, broad-context queries.
