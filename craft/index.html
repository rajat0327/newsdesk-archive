Presentation: Scaling LLM-Based Ranking Systems for Latency-Critical Search & Recommendation Workloads

LinkedIn details how it met strict P99 latency SLAs for LLM ranking by distilling a 7B parameter model down to 400M and compressing job contexts into single-token embeddings. It also highlights eliminating underlying system bottlenecks using custom flash attention masks, gc.freeze, Python GIL workarounds, and non-blocking CUDA memory copies.

Why it matters — Distilling models down to under 500M parameters combined with single-token embedding compression can deliver a 10x throughput increase for latency-critical production workloads.

Uber Cuts Translation Cache Memory by up to 90% While Keeping P99 Latency Below 1 MS

Uber redesigned its Go-based translation cache into a hybrid model that keeps keys and hot values in memory while offloading remaining entries to disk. This design reduced initial memory consumption by over 90% while maintaining hit rates above 99.9% and disk-backed miss P99 latency under 100 microseconds.

Why it matters — Hybrid cache architectures that offload cold values to disk significantly reduce Go garbage collection overhead and memory footprints without breaking sub-millisecond P99 SLAs.
