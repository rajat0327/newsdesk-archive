Previewing Ultrafast mode: GPT-5.6 Sol at up to 14X the speed

OpenAI is previewing 'Ultrafast' mode for GPT-5.6 Sol, powered by Cerebras hardware. The service tier delivers up to 750 output tokens per second, representing a speedup of up to 14x over standard inference.

Why it matters — Cerebras-powered inference enables ultra-low latency agentic workflows by delivering 750 tokens per second, making real-time multi-step reasoning viable.

Models

Introducing Muse Glimmer

Meta has released Muse Glimmer, a 30B open-weights model under an Apache 2.0 license. The model is optimized for end-to-end agentic task completion and demonstrates strong performance on complex benchmarks like SWE-bench.

Why it matters — Provides a highly capable, permissively licensed (Apache 2.0) 30B alternative to proprietary models specifically optimized for agentic workflows.

Auto mode is now the default in Claude Code for Pro, Max, and Team plans

Anthropic is making 'auto mode' the default setting for new sessions in Claude Code starting August 14th. This shift reflects high confidence in the tool's autonomous agentic capabilities.

Why it matters — Establishes autonomous, agentic code execution as the default developer workflow, reducing the need for manual step-by-step prompting.

Research

MindTopo reveals VLMs’ spatial reasoning abilities

Microsoft Research introduced MindTopo, a benchmark designed to evaluate topological reasoning in vision-language models (VLMs). It tests whether models can understand and manipulate spatial concepts like connectivity, enclosure, order, separation, and knots in static and dynamic contexts.

Why it matters — Provides a standardized framework to measure a VLM's spatial planning and reasoning capabilities beyond simple object recognition.
