Claude Haiku 5.5

Anthropic released Claude Haiku 5.5, a fast model priced at $0.10 per million input tokens and $0.50 per million output tokens. This pricing matches OpenAI’s GPT-6 Luna and represents a 10x reduction in cost compared to the previous Haiku 4.5.

Why it matters — Establishes the current market floor for frontier-class small model pricing at $0.10/$0.50 per million tokens.

Introducing Mistral Large 4: Le chonk

Mistral Large 4 is a 1-trillion parameter model with 49 billion active parameters, trained on 3,800 NVIDIA Grace Blackwell GPUs. The model features two reasoning modes and is scheduled for an open-weights release at the end of October 2026.

Why it matters — Provides a high-parameter open-weights alternative optimized for Grace Blackwell architecture with a 20:1 total-to-active parameter ratio.

Agent Lightning v1.0: A 3,500-Line Lightweight Agentic RL Framework for Training Agents with Real Harnesses

Agent Lightning v1.0 is a 3,500-line reinforcement learning framework that allows the same agent harness used in deployment to participate directly in training. It is designed to run natively on Kubernetes and eliminates the need to reimplement agents within the training framework.

Why it matters — Simplifies the transition from deployment to training by using a unified agent harness, reducing code duplication and framework overhead.

LegalOn halves Codex costs while maintaining development speed

LegalOn reduced daily Codex costs by 65% by routing specific tasks to different models within the OpenAI family, including Astra, Sol, and Luna. This strategy allowed them to maintain development speed while optimizing spend through model-task matching.

Why it matters — Demonstrates that a multi-model routing strategy can reduce operational costs by 65% without sacrificing performance.
